StreamSpace Video Website

Open index.html in Chrome, Edge, Firefox or Safari.

Features: responsive homepage, streaming sample videos, player, search, categories, trending, favorites and add video.

Add video: choose a local file to preview it during this session, or enter a public MP4/WebM URL for an entry that can be saved in this browser.

Important: this is a self-contained front-end demo. For a public video-sharing platform with permanent video uploads, accounts, transcoding, payments, copyright moderation, and a database, it needs a production backend and hosting.

To publish: upload index.html to a static hosting provider such as Netlify, Cloudflare Pages, or GitHub Pages. Public uploads require further engineering.
